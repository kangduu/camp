Node.js 文档按 [roadmap.sh Node.js Developer Roadmap](https://roadmap.sh/nodejs/) 的学习顺序补充，面向已经熟悉 JavaScript、准备理解服务端运行时和工程实践的读者。

Node.js 不是浏览器里的 JavaScript。它使用 V8 执行 JavaScript，但提供的是服务端运行时能力：文件系统、进程、网络、模块加载、包管理、流、线程/进程、调试与部署。阅读时要持续区分 JavaScript 语言语义、Node.js 标准库、操作系统能力、npm 包和框架行为。

## 推荐阅读路径

1. 先读 [Node.js 入门](./introduction.md)、[Node.js 文件执行](./execute.md)、[nvm](./nvm.md) 和 [npm](./npm.md)，建立运行、版本和包管理基础。
2. 再读 [模块系统](./modules.md)、[异步编程](./async-programming.md)、[错误处理](./error-handling.md)，理解 Node.js 代码组织、事件循环和错误边界。
3. 接着读 [环境变量与 CLI](./environment-cli.md)、[文件系统与路径](./files-paths.md)、[JSON 与数据交换](./json.md)，掌握脚本和工具开发常用能力。
4. 然后读 [API 开发](./api-development.md)、[认证与 JWT](./jwt.md)、[模板引擎](./template-engines.md)、[数据库访问](./databases.md)，覆盖服务端应用开发主线。
5. 最后读 [测试](./testing.md)、[日志](./logging.md)、[进程保活](./process-management.md)、[流](./streams.md)、[线程与进程](./threads-processes.md)、[调试与性能](./debugging-performance.md)，补齐工程化与生产运行能力。
